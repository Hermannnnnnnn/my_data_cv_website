Testing — Data Engineering

Load testing

Revived an underused PL/SQL testing framework: added test templates, expanded coverage beyond file ingestion, and prevented integrity issues before they reached the Data Vault and dimensional model.

Unit & regression testing

Built an automated testing tool in Python with GitHub, CI/CD and python, adding these technologies to the team's toolstack, knowing they would need to use them in the future when migrating to Databricks. The framework itself runs a comprehensive suite of tests, either on source ingestion (source to datavault) or presentation (datavault to dimensional model) and is still used today, replacing the tedious manual testing cycle we had before. Needless to say, we found a lot of data issues, sped up the testing phase and have gained increased business trust in the data.
