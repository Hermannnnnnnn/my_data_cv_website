Testing — Data Engineering

Load testing

I brought back to life a testing framework in PL/SQL that existed in our team but was not getting the love it needed. I added more test templates to the framework, broadened its scope to more than file ingestion tests, and thereby stopped integrity issues before entering the data vault and dimension model.

Unit & regression testing

I made an automated testing tool, using github, ci/cd and python, adding these technologies to the team's toolstack, knowing they would need to use them in the future when migrating to databricks. The framework itself fires off a whole batallion of tests, either on source ingestion (source to datavault) or presentation (datavault to dimensional model) and is still used today, replacing the tedious manual testing cycle we had before. Needless to say, we found a lot of data issues, sped up the testing phase and have gained more more trust in our data from business.
